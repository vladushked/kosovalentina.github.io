
# Минималистичный сайт портфолио

Сайт на React + Vite, подготовленный для автоматической публикации в GitHub Pages
с кастомным доменом **kosovalentina.ru**.

## Локальный запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

Артефакты сборки попадают в папку `dist/`.

## Автодеплой в GitHub Pages

В репозитории уже добавлен workflow:

- `.github/workflows/deploy.yml` — автосборка и автодеплой при `push` в `main`
- `CNAME` — кастомный домен `kosovalentina.ru`

После каждого пуша в ветку `main` GitHub Actions автоматически публикует сайт.

## Что включить в настройках GitHub

1. Откройте репозиторий → **Settings** → **Pages**.
2. В разделе **Build and deployment** выберите **Source: GitHub Actions**.
3. Убедитесь, что деплой workflow успешно отрабатывает во вкладке **Actions**.

## DNS для домена kosovalentina.ru

У регистратора/в DNS-провайдере настройте:

- `A` записи для корневого домена `@` на IP GitHub Pages:
  - `185.199.108.153`
  - `185.199.109.153`
  - `185.199.110.153`
  - `185.199.111.153`
- (опционально) `CNAME` для `www` → `kosovalentina.ru`

После обновления DNS (обычно от нескольких минут до 24 часов) сайт будет доступен на вашем домене.
